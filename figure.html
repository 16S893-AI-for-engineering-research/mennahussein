Lossless Convexification — Fig. 3 Regenerated from the Math

Fig. 3 in "Lossless convexification of control constraints for a class of nonlinear optimal control problems" (Systems & Control Letters, 2012) is captioned "Optimal trajectory for nonlinear soft landing problem." Rather than digitizing that image, I re-derived it: I set up and solved Problem 3 directly from the paper's equations and parameters, using the exact dynamics, bounds, and boundary conditions stated in Section 5.

Read the Original Paper (PDF)

The Math Being Solved

Problem 3 (Nonlinear-Gravity Soft Landing), Eqs. (26)–(29) of the paper:

minφ,t_f J = ∫₀^t_f ‖φ(t)‖ dt
subject to:
r̈(t) = g(r(t)) + φ(t)/m(t)  (C_D = 0 for this example)
0 < ε₁ ≤ ‖φ(t)‖ ≤ ε₂  (nonconvex control constraint)
r(0) = r₀, ṛ(0) = ṛ₀, r(t_f) = t_p, ṛ(t_f) = t_v

Theorem 1 shows that solving the convex-relaxed version (Problem 2 — replacing ‖φ‖ with a slack variable ϑ bounded by [ε₁, ε₂] and constrained by ‖φ‖ ≤ ϑ) yields the globally optimal solution to the original nonconvex problem, provided an observability condition on the dynamics holds (Condition 1 / Corollary 1). This soft-landing problem satisfies that condition, so the relaxation is lossless.

Paper's stated simulation parameters (Section 5), used here exactly: ε₁ = 2 m/s², ε₂ = 10 m/s², r₀ = [2, 8]×10⁴ m, ṛ₀ = t_p = t_v = 0, N = 15 discretization steps, optimal t_f* = 490 s.

How It Was Regenerated

🧮

Direct Transcription

Zero-order-hold control over N = 15 steps (matching the paper), with the discrete dynamics in Eq. (A.2) of the appendix. Solved as a nonlinear program with SciPy's SLSQP, rather than the paper's MILP-with-piecewise-linear-gravity formulation — both approaches target the same continuous problem.

🌙

Nonlinear Gravity

A smooth altitude-varying field g(h) = g₀·(R/(R+h))² is used directly as g(r) in the dynamics — the actual nonlinear field the paper's Fig. 2 piecewise-linear model is built to approximate — so the solved problem retains the nonlinearity that motivates Theorem 1.

🎯

Relaxed Constraint

The nonconvex constraint ε₁ ≤ ‖φ‖ ≤ ε₂ is relaxed to Problem 2's convex form (slack variable ϑ ∈ [ε₁, ε₂], ‖φ‖ ≤ ϑ) exactly as the paper prescribes, then solved — the plotted result is the relaxed problem's solution, which Theorem 1 guarantees equals the nonconvex problem's optimum.

Regenerated Fig. 3 — Optimal Descent Trajectory

Downrange vs. altitude from r₀ = (2×10⁴, 8×10⁴) m to touchdown at the origin. Red arrows show the thrust-acceleration vector φ(t)/m at each discretization node — note they point mostly upward/retrograde to arrest the descent, growing sharply only in the final braking phase.

Thrust-Acceleration Magnitude vs. Time

Dashed lines mark the nonconvex feasible bounds ε₁ = 2 m/s² and ε₂ = 10 m/s². As Theorem 1 predicts, the optimal relaxed solution sits exactly on the lower bound for nearly the entire flight — the minimum-fuel solution naturally avoids the forbidden interior region (0, ε₁) without it ever being explicitly excluded from the relaxed problem — and only increases in the final node to execute the terminal braking maneuver.

Result Check Against the Paper

✅

Terminal Conditions

The regenerated solution reaches r(t_f) = (0, 0) and ṛ(t_f) = (0, 0) to numerical precision — matching the paper's stated boundary conditions t_p = t_v = 0.

📉

Bang-Then-Modulate Structure

Thrust magnitude stays at the nonconvex lower bound ε₁ = 2 m/s² for 14 of 15 steps, rising only at final approach — the qualitative signature the paper reports for Fig. 3/4 as evidence that "the nonconvex control magnitude constraints are satisfied as predicted by Theorem 1."

⏱️

Final Time

Solved with the paper's reported optimal t_f* = 490 s fixed, rather than re-running the golden-search line search over t_f — a direct, self-contained check that this t_f is consistent with a feasible, boundary-satisfying optimal solution.
